# ClinicOne Predictive Analytics

`clinic_analytics` is official addon **#39 / 39**.

It adds:
- governed KPI catalog;
- branch/company analytical snapshots;
- trend and threshold status;
- transparent baseline forecasting;
- 30/60/90-day patient retention cohorts;
- actionable insight workflow;
- scheduled snapshot/forecast/cohort generation;
- Dashboard/Reports smart-button integration;
- optional Integration API events;
- Audit evidence for analytics workflow actions.

It never accepts arbitrary source model/domain expressions from users.
