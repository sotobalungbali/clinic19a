ClinicONe — Accounts Payable

Vendor Bills • Approvals • Posting • Payments • Aging

A production-ready Accounts Payable module to manage vendor bills → approvals → posting → payments → aging, fully integrated with the ClinicONe suite. Compatible with Odoo 18 Community Edition.

Odoo 18 CE Multi-company Multi-currency Approval Workflow Payments Aging & Analytics

Overview

Streamline vendor liabilities from bill intake to settlement. Enforce multi-level approvals, post to General Ledger, reconcile partial/full payments, and monitor aging buckets. Deep links to Purchase, Inventory valuation, Billing, AR, and Finance keep financial data consistent and auditable.

Key Features

  • Vendor bill lifecycle: Draft → To Approve → Approved → Posted → Partially Paid → Paid → Cancelled
  • Multi-level approval (role-based) with chatter & activities
  • Partial / full payments, residual tracking, payment state
  • Aging buckets (Not Due, 0–30, 31–60, 61–90, 90+ days)
  • Payment terms & due date computation
  • Analytic account/tags for cost attribution
  • Email reminders for upcoming/overdue payments
  • Soft-coupled integrations with Purchase, Inventory, Billing, AR, Finance

Core Models

  • clinicone.account.payable — AP master document (header)
  • clinicone.account.payable.line — AP lines (amounts, taxes, analytic)
  • account.move (inherit) — vendor bill posting
  • account.payment (inherit) — vendor payments & reconciliations

Notes: model aliases for clinic.account.* can be provided during namespace normalization.

Holistic Integrations (ClinicONe)

Works seamlessly with: clinic_base, clinic_patient, clinic_doctor, clinic_booking, clinic_treatment, clinic_billing, clinic_ar, clinic_finance, clinic_accounting, clinic_inventory, clinic_ecommerce, clinic_membership, clinic_feedback, clinic_reports, clinic_dashboard, clinic_wallet, clinic_package, clinic_pricing, clinic_room_device, clinic_hr, clinic_portal, clinic_marketing, clinic_l10n_id, clinic_audit.

Integrations are decoupled via relations, activities, server actions, and mail templates to keep modules independently deployable.

Installation

  1. Add this addon to your Odoo addons_path.
  2. Update Apps list, search ClinicONe: Accounts Payable.
  3. Install; dependencies resolve automatically.

Configuration

  • Set default AP Journal and Sequences.
  • Define Payment Terms and vendor-specific preferences.
  • Review Email Templates for due reminders.
  • Enable Cron for aging refresh & notifications.

Security

  • Groups: AP Accountant, AP Manager, Finance Admin
  • Record Rules: company / branch scoping
  • Auditable approvals via chatter & activities

Reports

  • AP Aging (by bucket, vendor, company)
  • Vendor Payables Summary
  • Cashflow (AR & AP consolidated)
  • Vendor Bill print (QWeb)

Performance Notes

  • Index frequently filtered fields: vendor, state, due date, company
  • Prefer computed stored fields for list views
  • Archive settled AP documents periodically in high-volume setups

Assets

  • JS: ap_dashboard.js, ap_list_improvements.js
  • QWeb: report_aging_templates.xml, payable_summary_templates.xml
  • SCSS: ap_dashboard.scss
