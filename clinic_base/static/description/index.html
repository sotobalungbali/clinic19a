ClinicOne — Base

Fundamental Models • Shared UI • Utilities • Security

clinic_base provides the shared foundation for the ClinicOne suite: core models, mixins, web assets, demo data hooks, and security groups used by downstream modules (patients, doctors, booking, treatment, billing, and more) — fully compatible with Odoo 18 Community Edition.

Odoo 18 CE No Menu (Base) Multi-company APIs & Mixins

Overview

The base layer that standardizes naming, shared fields, and UI behavior across ClinicOne modules. It keeps modules loosely coupled but consistent, so you can install features independently without duplicating the plumbing code.

Key Features

  • Core reference models (clinic.company.profile, clinic.tag, clinic.note)
  • Common mixins: code/name sequence, active/archive, company/branch scope
  • Shared widgets, Kanban badges, and QWeb snippets
  • Centralized security groups & access templates
  • Demo hooks for downstream modules
  • Technical settings registry (no top-level menu)

Core Models

  • clinic.company.profile — clinic identity (legal name, branding colors, terms)
  • clinic.tag — generic tagging for patients, treatments, and documents
  • clinic.note — lightweight internal notes with attachments & chatter
  • res.company (extended) — clinic-specific options & sequences
  • mail.activity (extended) — default activity types & templates

Designed to avoid creating a new app icon or home menu: this is a base dependency.

Integrations (Downstream)

Seamlessly used by: clinic_patient, clinic_doctor, clinic_booking, clinic_treatment, clinic_billing, clinic_inventory, clinic_membership, clinic_reports, clinic_dashboard.

Installation

  1. Place this addon in your Odoo addons_path.
  2. Update Apps list, search ClinicOne: Base.
  3. Install. No top-level menu will be added.

Configuration

  • Company Profile: logo, brand color, document footers
  • Sequences for shared objects (codes and references)
  • Default activity types & mail templates

Security

  • Groups: Clinic User, Clinic Manager, Clinic Admin
  • Record rules: company/branch domain isolation

Assets

  • SCSS: clinic_base.scss — color tokens & badges
  • JS: clinic_base_widgets.js — small UX helpers
  • QWeb: clinic_base_templates.xml — shared snippets

Performance Notes

  • No heavy computes; only lightweight helpers
  • Indexes on frequently filtered fields
  • Neutral in upgrade chains to minimize conflicts
