ClinicOne — Care Plan & Protocol Library

Care Plans • Protocol Templates • Step Scheduling • Adherence & Outcomes • Billing & eMAR Links

Pustaka care plan terpusat dan protocol template untuk menyusun perawatan pasien secara konsisten, mengelola langkah/step dengan penjadwalan, melacak adherence & progress, terhubung ke treatment sessions, prescription/eMAR, booking, dan billing — terintegrasi penuh di ekosistem ClinicOne (Odoo 19 Community Edition).

Odoo 19 CE Multi-company Mail/Activities eMAR & Sessions Billing Links

Overview

Modul ini memusatkan desain Care Plan berbasis Protocol sehingga perawatan lebih terstandardisasi, terukur, dan mudah diaudit. Engineer dapat memodelkan protocol step, menghasilkan plan lines otomatis, menyusun treatment sessions, dan menghubungkan ke prescriptions (eMAR), consent, booking, inventory/products, serta billing. Dashboard adherence & outcome membantu evaluasi klinis.

Key Features

  • Care Plan lifecycle: Draft → Active → On Hold → Completed → Archived
  • Protocol Templates dengan steps, durasi, dependensi, dan instruksi
  • Generate Plan Lines otomatis dari protocol (editable)
  • Scheduling treatment session + smart buttons ke Encounter/Booking
  • Adherence & Progress (step/session completion, % progress)
  • eMAR Links: prescriptions & administration (orders → administration)
  • Billing Integration: estimated amount, invoiced amount, remaining
  • Consent & Attachments untuk compliance, dengan record rules
  • Reports: Care Plan Summary, Protocol Adherence, Outcomes
  • Audit Trail via mail.thread & activity mixin

Core Models

  • clinic.care.plan — master care plan & lifecycle
  • clinic.care.protocol — protocol template (reusable)
  • clinic.care.plan.line — item/step turunan protocol
  • clinic.care.protocol.step — definisi langkah protocol

Relasi ke: patient, doctor, practitioners, treatments, sessions, prescriptions, invoices.

Holistic Integrations (26 Modules)

Mulus dengan: clinic_base, clinic_patient, clinic_doctor, clinic_booking, clinic_treatment, clinic_pricing, clinic_inventory, clinic_room_device, clinic_wallet, clinic_membership, clinic_package, clinic_billing, clinic_ar, clinic_ap, clinic_finance, clinic_accounting, clinic_ecommerce, clinic_portal, clinic_feedback, clinic_reports, clinic_dashboard, clinic_hr, clinic_marketing, clinic_l10n_id, clinic_audit.

Installation

  1. Tambahkan addon ke addons_path Odoo.
  2. Update Apps list, cari ClinicOne — Care Plan & Protocol Library.
  3. Install; dependensi akan terpasang otomatis.

Configuration

  • Konfigurasi Sequence untuk nomor Care Plan.
  • Definisikan Protocol Templates dan Protocol Steps.
  • Atur Security Groups dan record rules untuk confidentiality.
  • Opsional: mapping ke Billing, eMAR, Booking, Inventory.

Security

  • Groups: Care Plan User, Care Plan Manager, Clinical Compliance.
  • Record Rules: scope perusahaan, kontrol akses patient-sensitive.
