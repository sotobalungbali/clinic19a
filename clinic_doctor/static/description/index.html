ClinicOne — Doctor Management & Scheduling

Doctors • Specialties • Working Hours • Availability • Appointments

clinic_doctor manages the complete doctor roster and scheduling lifecycle: professional profiles, specialties, working hours, availability slots, leaves, and patient appointments. It integrates seamlessly with other ClinicOne modules for treatment, billing, inventory, and more — fully compatible with Odoo 18 Community Edition.

Odoo 18 CE Scheduling Multi-company Portal-ready HR Bridge (optional)

Overview

Centralize doctor information and streamline bookings from template-based working hours to materialized availability slots. Automate reminders and reduce conflicts with room-aware scheduling. Connect appointments to treatment sessions and billing upon completion.

Key Features

  • Doctor profiles (license, authority, seniority, specialties)
  • Working hours via resource.calendar and weekly Schedule Rules
  • Availability Slots materialized from rules with capacity & buffers
  • Leaves / Exceptions (vacation, blackout dates) with automatic conflict checks
  • Appointment lifecycle: draft → confirmed → checked-in → in-treatment → done / no-show / canceled
  • Reminders, rescheduling, and no-show policies (cron-enabled)
  • Room-aware scheduling (via clinic_queue_room) and device awareness
  • Portal booking (optional) for patient self-service
  • Dashboards & KPIs (utilization, wait time, no-show rate, revenue per doctor)

Data Model Highlights

  • clinic.doctor — linked to contact (res.partner) and optionally HR employee (bridge)
  • clinic.specialty — hierarchical specialties with unique codes
  • clinic.schedule.rule → clinic.availability.slot — templated → concrete slots
  • clinic.doctor.leave — time-off and blackout periods
  • clinic.appointment — room-aware booking with state machine

HR/Payroll kept optional via clinic_doctor_hr bridge (auto-create & sync hr.employee).

Integrations

Works end-to-end with: clinic_patient, clinic_booking, clinic_treatment, clinic_billing, clinic_ar, clinic_ap, clinic_finance, clinic_accounting, clinic_inventory, clinic_ecommerce, clinic_membership, clinic_feedback, clinic_reports, clinic_dashboard, clinic_wallet, clinic_package, clinic_pricing, clinic_room_device, clinic_portal, clinic_marketing, clinic_l10n_id, clinic_audit, plus:

  • clinic_queue_room: provides clinic.room and queue/kiosk features for walk-ins
  • clinic_doctor_hr: optional HR bridge for hr.employee and payroll readiness

Installation

  1. Place this addon in your Odoo addons_path.
  2. Update Apps list and search ClinicOne: Doctor Management & Scheduling.
  3. Install along with clinic_queue_room (required) and clinic_doctor_hr (optional).

Configuration

  • Define specialties and assign them to doctors
  • Set working hours (resource calendars) and create schedule rules
  • Generate availability slots and configure reminder policies
  • (Optional) Enable HR bridge: auto-create/sync employees; strict HR mode

Security

  • Groups: Receptionist, Doctor, Clinic Manager, Clinic Admin
  • Access & record rules aligned to multi-company isolation

Reports & KPIs

  • Utilization by doctor/room
  • No-show rate, wait time, lead time
  • Revenue per doctor/service (with Billing/Accounting)

Automation

  • Slot regeneration and availability refresh
  • Appointment reminders and follow-ups
  • No-show detection (grace period configurable)
