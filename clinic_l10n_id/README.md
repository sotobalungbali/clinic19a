# ClinicOne Indonesia Localization

Version: **19.0.1.0.1**

Blueprint responsibility:
> Localizes system for Indonesia, adds PPN, tax reports, and invoice numbering rules.

This addon deliberately builds on Odoo 19 official modules:
- `l10n_id`
- `l10n_id_efaktur_coretax`

ClinicOne adds governance, reporting, readiness checks, and safe numbering policy.
It does not duplicate Odoo tax definitions or Coretax XML generation.

Runtime status: **PENDING** until installation and smoke testing on the user's
Odoo 19 CE environment.
