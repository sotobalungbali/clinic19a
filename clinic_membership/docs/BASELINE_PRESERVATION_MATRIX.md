


# Baseline Preservation Matrix
Core baseline capabilities retained: membership plan/tier/term/pricing; plan benefits; contract lifecycle; benefit usage; vouchers; loyalty points; holds/freezes; accounting invoice creation; patient/booking/treatment integration.
Historical integration files that directly referenced optional/future/historical models are not blindly re-imported. Their intent is preserved through typed current-model bridges or the integration-event outbox. Numeric-prefix files are excluded as user backups.
