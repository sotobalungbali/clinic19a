ClinicOne — Patient Management

MRN • Identifiers • Contacts • Allergies • Conditions • Vitals

Kelola data pasien secara menyeluruh: registrasi dengan MRN otomatis, identitas legal, kontak darurat, alergi & kondisi klinis, serta tanda vital—terintegrasi penuh dengan alur klinik dan modul finansial di Odoo 18 Community Edition.

Odoo 18 CE Multi-company Mail/Activities Security/Audit Interop Ready

Overview

Modul ini menyediakan fondasi rekam data pasien lintas layanan klinik kecantikan: mulai dari pembuatan MRN (Medical Record Number), identifiers (NIK/BPJS/Passport), kontak & relasi, alergi, kondisi klinis, hingga tanda vital dengan guard rentang klinis dan kalkulasi BMI. Dirancang agar soft-coupled ke modul lain (Booking, Encounter, Billing, Consent/Legal, dsb).

Key Features

  • MRN Otomatis dengan prefix & format fleksibel (sequence & guard)
  • Identifiers: NIK, BPJS, Passport, SIM, NPWP, Other (1 primary/ pasien)
  • Emergency Contacts + normalisasi telepon (E.164)
  • Allergies: kategori, reaksi, severity, anaphylaxis risk, verifikasi
  • Conditions: kategori (chronic/acute), clinical & verification status
  • Vitals: BP, HR, RR, SpO₂, suhu (°C/°F), GCS (E/V/M), BMI
  • Stages pasien (New → Registered → Active → …) dengan statusbar klik-able
  • Mail Templates & Activities (welcome & follow-up otomatis)
  • Security & Audit: multi-company guard, chatter, trail create/write
  • Interop helper untuk lintas modul (booking, consent, billing)

Core Models

  • clinic.patient — master pasien & MRN
  • clinic.patient.identifier — identitas resmi
  • clinic.patient.contact — kontak darurat / hubungan
  • clinic.patient.allergy — alergi & risiko
  • clinic.patient.condition — riwayat/diagnosis kondisi
  • clinic.patient.vital — catatan tanda vital
  • clinic.patient.stage — pipeline status pasien

Integrasi name_get konsisten: [MRN] Name untuk pencarian cepat.

Holistic Integrations

Terhubung mulus dengan: clinic_doctor, clinic_booking, clinic_treatment, clinic_queue_room, clinic_encounter, clinic_consent, clinic_orders, clinic_billing, clinic_ar, clinic_ap, clinic_finance, clinic_accounting, clinic_inventory, clinic_membership, clinic_wallet, clinic_package, clinic_pricing, clinic_room_device, clinic_portal, clinic_marketing, clinic_feedback, clinic_ecommerce, clinic_l10n_id, clinic_audit, clinic_reports, clinic_dashboard.

Integrasi bersifat soft-coupled via relasi, server action, mail template, & event log sehingga modul tetap dapat dipasang/ditingkatkan secara independen.

Installation

  1. Salin addon ke addons_path Odoo.
  2. Update Apps list, cari ClinicOne — Patient Management.
  3. Install; dependensi terpasang otomatis.

Configuration

  • Sesuaikan sequence MRN (prefix, padding).
  • Definisikan stages pasien sesuai SOP klinik.
  • Atur mail template welcome/follow-up (opsional).
  • Set parameter ICP: normalisasi telepon, default country, dsb.

Security

  • Groups: Patient User, Patient Manager, Patient Admin.
  • Record Rules: scope perusahaan & pembatasan akses PII.
