ClinicOne — Clinical Queue & Room Management

Queueing • Room Allocation • Live Dashboards • Kiosk Check-in

A production-ready module to orchestrate patient flow from check-in → queue → room → treatment → completion, with deep integrations across the ClinicOne suite. Compatible with Odoo 18 Community Edition.

Odoo 18 CE Multi-company Mail/Activities Dashboard Kiosk

Overview

This module centralizes queue operations, room allocation, and real-time visibility for front desk teams, clinical staff, and managers. It introduces configurable queue stages with policies (requirements, auto-assign), WIP limits, SLA hints, and hooks to billing, insurance, inventory, and feedback.

Key Features

  • Queue lifecycle: Waiting, In Progress, On Hold, Done, Cancelled, No Show
  • Kanban stages: sequence, color, fold, transition whitelist, WIP limit
  • Room management: types, capacity, statuses, auto-assignment policies
  • Doctor/Treatment binding + optional Procedure Session creation
  • Live backend dashboard & touch-friendly kiosk check-in
  • SLA hints (waiting/service) + mail/server action hooks on enter/exit stage
  • Deep integrations: Patient, Booking, Treatment, Billing, Insurance, Inventory, Feedback, Telemedicine

Core Models

  • clinic.queue — queue entry, timing, stage/state, relations
  • clinic.room — room catalog, types, capacity, status
  • clinic.queue.stage — stage policies, SLA, transitions
  • clinic.room.assignment — rooming history & conflicts
  • clinic.queue.event — auditable lifecycle events

Legacy compatibility aliases are provided for older clinicone.clinical.* model names during migration.

Holistic Integrations (26 Modules)

Seamless with: clinic_base, clinic_patient, clinic_doctor, clinic_booking, clinic_treatment, clinic_billing, clinic_ar, clinic_ap, clinic_finance, clinic_accounting, clinic_inventory, clinic_ecommerce, clinic_membership, clinic_feedback, clinic_reports, clinic_dashboard, clinic_wallet, clinic_package, clinic_pricing, clinic_room_device, clinic_hr, clinic_portal, clinic_marketing, clinic_l10n_id, clinic_audit, clinic_insurance, clinic_telemedicine.

Installation

  1. Add this addon to your Odoo addons_path.
  2. Update Apps list, search ClinicOne: Clinical Queue & Room Management.
  3. Install; dependencies auto-resolve.

Configuration

  • Define Queue Stages (defaults, transitions, WIP, SLA, hooks).
  • Create Room Types & Rooms, set statuses.
  • Verify sequence clinic.queue is active.
  • Bind optional mail templates / server actions on stage enter/exit.

Security

  • Groups: Queue Receptionist, Clinical Staff, Room Supervisor, Admin.
  • Record Rules: company scope, active queues, patient portal visibility.

Demo & Testing

  • Demo data: demo_rooms.xml, demo_queue.xml (for sandbox only).
  • Unit tests: queue flow, room allocation, security.
  • UAT scenarios: walk-in vs appointment, auto-assign, SLA breach, billing trigger, feedback request.

Performance Notes

  • Index frequently filtered fields: stage_id, company_id, patient_id, doctor_id, room_id, state, checkin_time.
  • Use domains in dashboards; avoid heavy computes in list views.
  • Periodically archive completed queues for high-volume environments.

Assets

API Endpoints

Upgrade & Migration
