# ClinicOne Central Reporting Engine

Version: **19.0.1.0.0**

Official ClinicOne addon: **28 of 39**

Blueprint:
> Central reporting engine for financial, operational, and clinical reports.

The addon does not move source ownership.  It reads existing ClinicOne records,
stores governed report snapshots, exposes traceable metrics/details, supports
PDF/CSV output, and provides a stable metric layer for the later
`clinic_dashboard` addon.

Runtime status: **PENDING** until activation and smoke testing succeeds on the
target Odoo 19 CE environment.
