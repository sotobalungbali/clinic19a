ClinicOne — Treatment Catalog & Pricing

Catalog • Variants • Pricelists • Membership • Surcharge • Insurance • eCommerce

Pondasi penetapan harga enterprise untuk klinik kecantikan di Odoo 18 Community Edition. Kelola katalog treatment sebagai service product, variant/therapist level, atur pricelist (membership tier, packages/bundles, promos/seasonal), dukung surcharge (level terapis, room/equipment, prime time), serta insurance coverage & co‑pay dengan integrasi penuh ke Booking → Encounter/Procedure → Billing dan eCommerce.

Overview

Modul ini menyatukan aturan harga klinik dalam sub‑sistem terstruktur: Treatment Catalog, Variant/Therapist Level, Pricing Rules, Surcharge, dan Insurance Coverage. Semua harga berjalan di atas Odoo Pricelist melalui Clinic Pricelist Bridge, sehingga tetap kompatibel dengan mekanisme standar Odoo, namun kaya konteks klinik (channel, membership, promo tag, waktu).

Key Features

  • Treatment Catalog (service product) dengan gambar, deskripsi, durasi, kategori
  • Variants (level terapis, teknik, dosis) dan delta harga
  • Pricelist Extensions: scope ke treatment/variant, membership tiers, promo tags, channel
  • Membership Pricing: fixed price / % / fixed discount + stacking rules & exclusivity
  • Surcharge Engine: therapist level, room/equipment khusus, prime time
  • Insurance Engine: eligibility, deductible, coverage %, co‑pay, authorization
  • Package/Bundle: entitlement, redemption, consumption log
  • eCommerce Integration: web price (tanpa surcharge/insurance), package entitlement policy
  • Audit: event terstruktur untuk pricing/surcharge/insurance/billing

Core Models

  • clinic.treatment.catalog — master treatment (service)
  • clinic.treatment.variant — turunan treatment (level, teknik)
  • clinic.pricing.rule — promo/seasonal/coupon rules
  • clinic.surcharge.rule — room/equipment/prime time/therapist
  • clinic.insurance.rule — coverage/co‑pay/deductible/authorization
  • clinic.package.* — package/bundle & entitlements
  • product.pricelist (extension) — ClinicOne scope & helper
  • clinic.pricelist.bridge — jembatan ke algoritma Odoo Pricelist
  • clinic.membership.benefit.rule — benefit harga per tier
  • clinic.audit.event — audit log terpusat

Semua model mengikuti konvensi Odoo 18 CE dan kompatibel multi‑company.

Holistic Integrations (ClinicOne)

Terintegrasi mulus dengan: clinic_base, clinic_patient, clinic_doctor, clinic_booking, clinic_billing, clinic_ar, clinic_ap, clinic_finance, clinic_accounting, clinic_inventory, clinic_room_device, clinic_ecommerce, clinic_membership, clinic_feedback, clinic_reports, clinic_dashboard, clinic_wallet, clinic_package, clinic_portal, clinic_marketing, clinic_l10n_id, clinic_audit dan lainnya dalam proyek ClinicOne.

Integrasi soft‑coupled melalui relasi opsional, hooks, dan bridges sehingga modul dapat dipasang/ditingkatkan secara independen tanpa mematahkan alur lain.

Pricing Engine

  • Base price dari Odoo Pricelist via Clinic Pricelist Bridge
  • Context‑aware: channel (booking/eCommerce/back‑office), promo tags, waktu
  • Guardrail minimum price per treatment/variant
  • Non‑intrusive: tidak mengubah algoritma inti Odoo

Membership

  • Benefit rule per tier: fixed price, % discount, nominal discount
  • Window tanggal, min qty, channel, promo tags
  • Stacking & exclusivity antar rule membership
  • Log penerapan untuk pelacakan & audit

Surcharge & Insurance

  • Surcharge: therapist level, room/equipment, prime time
  • Insurance: eligibility, deductible, coverage, co‑pay, authorization
  • Estimasi di Booking, real cost di Encounter
  • Transparansi via catatan komponen biaya

End‑to‑End Flow

  1. Booking: estimasi biaya (pricelist + membership + promo) → surcharge/insurance (preview)
  2. Encounter/Procedure: hitung biaya riil + redeem package
  3. Billing: invoice pasien (co‑pay) + opsional invoice insurer
  4. eCommerce: web price (tanpa surcharge/insurance) + entitlement paket
  5. Audit: event pricing/surcharge/insurance/invoice terdokumentasi
