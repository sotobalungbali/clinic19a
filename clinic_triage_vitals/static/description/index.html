Key Features

⚡ Triage Session

  • Lifecycle: draft → in_progress → completed / referred / cancelled
  • Arrival, waiting, duration & SLA tracking
  • Nurse/Doctor assignment, notes, and chatter

🎚️ Triage Level

  • SLA (minutes) & priority weight
  • Auto-escalation (threshold & target level)
  • Vitals thresholds & guidelines

🏷️ Triage Tags

  • Flexible classification (Trauma, Allergy, Pediatric, Aesthetic, …)
  • Queue/Room recommendations & default activities
  • Optional billing hooks (service/fee)

🩺 Vitals Intake

  • Temperature, HR, RR, SpO₂, BP, BMI, GCS, etc.
  • Abnormal flag & notes
  • Multiple readings per session

📥 Queue & Room Hints

  • Recommend clinic.room.type
  • Default clinic.queue.stage per level/tag
  • Optional dependency on queue/room modules

💳 Billing-Ready

  • Billable toggle & default fee
  • Service product from level/tag
  • Create customer invoice from session

Workflow

UI language: All in-app labels, helps, and messages are English. This description page targets implementers/admins.

Business Flow

  • Arrival & Registration → create triage session (arrival time auto).
  • Start Triage → capture vitals, select level & tags, SLA tracked.
  • Queue/Room → recommended room type & default queue stage are suggested.
  • Billing (optional) → mark billable, set fee/product, generate invoice.
  • Complete/Refer/Cancel → finalize; sessions can be reopened when needed.

State Machine

[draft] --Start--> [in_progress] --Complete--> [completed]
     │                         └─Refer──> [referred]
     └──Cancel───────────────> [cancelled] ──Reopen──> [draft]

Installation

  1. Ensure dependencies are installed (see Integrations).
  2. Place the module in your addons path.
  3. Update Apps list and install: odoo-bin -d <db> -u clinic_triage_vitals

Optional: install queue/room modules to enable room recommendations and queue stage defaults.

Initial Configuration

  • Sequences: clinic.triage.session (auto-loaded).
  • Seed Levels: Red / Yellow / Green / Blue.
  • Groups & Access: loaded via security/ & data/res_groups.xml.
  • Activity Types: optional defaults for triage follow-up.
Tip: Customize triage level thresholds and billing defaults to match your clinical policy.

Usage

  1. Create a new Triage Session for the arriving patient.
  2. Click Start to begin; record Vitals Intake.
  3. Select appropriate Triage Level and optional Tags.
  4. Review SLA target; system flags breach if missed.
  5. (Optional) Mark Billable and create invoice if applicable.
  6. Finish with Complete, or Refer/Cancel as needed (can later Reopen).

FAQ

Does the module enforce vitals thresholds?

Thresholds on levels are guidance values. Enforcement can be added via automated actions or custom rules.

Is invoicing mandatory?

No. Billing is optional. You can keep triage sessions non-billable or bill only certain levels/tags.

Can we customize scoring or SLA?

Yes. Priority score and SLA logic are computed fields and can be extended via inheritance.
